## 3. Parts Generated by AI
* **Backend Framework**: Complete Express server (`server.js`), JWT verification and role authentication middleware (`src/middleware/auth.js`), API routes, controllers (`authController.js`, `leaveController.js`, `employeeController.js`), and database pool configurations.
* **Dual-Driver Database Handler**: Logic inside `src/services/db.js` checking PostgreSQL database pool availability and falling back to a structured JSON file DB (`data/db.json`) with auto-seeding.
* **Frontend React Architecture**: Single Page Application shell (`App.jsx`), global state wrapper (`context/AuthContext.jsx`), circular SVG balance trackers (`DashboardStats.jsx`), search directory dashboards, request forms, and manager approval queues.
* **Core CSS Styles**: Glassmorphism design elements, light mode colors, button hover actions, and popup modal animations.

## 5. Technical Issues Faced & Resolutions

| Issue Faced | Impact | Resolution |
| :--- | :--- | :--- |
| **PostgreSQL Unavailability** | The system would crash on launch if local Postgres database credentials weren't active. | Programmed `db.js` to automatically test connectivity. If PG is down, it seamlessly falls back to a file-based JSON DB, guaranteeing out-of-the-box local execution. |
| **Active Session Overwrite** | Standard user registration routes return a JWT token, which would log out the Manager when they tried to add a new employee. | Built a dedicated endpoint `POST /api/employees/create` restricted to managers. It hashes the password and registers the user to the database *without* overriding the manager's active login token. |
| **Desktop Popup Misalignment** | The `.sidebar-backdrop` class was nested inside a mobile media query, causing the modal to render at the bottom of the page on desktop. | Created a global `.modal-overlay` class outside the media query, applying flex centering and fixed overlay styling on all screen viewports. |
| **Form Transparency Contrast** | Using `glass-panel` styling made the registration card translucent, causing text to overlap and reduce legibility on busy lists. | Replaced the glass classes on the registration card with a solid `#ffffff` backdrop styling and custom shadow shadows to make it opaque. |
